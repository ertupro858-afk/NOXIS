# NOXIS V1.0

NOXIS V1.0, Windows Batch dili kullanılarak geliştirilmiş deneysel bir projedir. Bu proje, Batch komut dosyalarının sistem üzerinde gerçekleştirebileceği işlemleri göstermek, zararlı yazılımların temel çalışma mantığını incelemek ve güvenlik araştırmaları için örnek oluşturmak amacıyla hazırlanmıştır.

Proje içerisinde; konsol tabanlı arayüzler, uyarı ekranları, görsel efektler, sistem ayarlarını değiştirmeye yönelik örnekler, kalıcılık (Persistence) mantığı, dosya işlemleri ve çeşitli otomasyon senaryoları bulunmaktadır. Bazı özellikler yalnızca simülasyon niteliğinde olup görsel amaçla hazırlanırken, bazıları ise Windows Batch'in izin verdiği gerçek sistem işlemlerini örneklemektedir.

## Özellikler

* Konsol tabanlı kullanıcı arayüzü
* Uyarı ekranları ve yükleme animasyonları
* Glitch ve görsel efektler
* Sistem işlemlerini simüle eden modüller
* Dosya ve klasör işlemleri
* Batch diliyle geliştirilmiş otomasyon örnekleri
* Kalıcılık (Persistence) mantığının örneklenmesi

## Uyarı

Bu proje yalnızca eğitim, araştırma, analiz ve test amaçlı paylaşılmaktadır.

Gerçek bilgisayarlarda çalıştırılması önerilmez. Testlerin yalnızca sanal makine (Virtual Machine) veya izole edilmiş güvenli ortamlarda yapılması tavsiye edilir.

Projeyi kullanan herkes yaptığı işlemlerden kendisi sorumludur. Proje sahibi, izinsiz veya kötü niyetli kullanımlardan doğabilecek herhangi bir zarardan sorumlu değildir.
